# Best Wishes

A quiet bilingual 3D landscape for wishes and everyday reflection.

Open `index.html` through a static web server. The public edition lives at
https://wilixx.github.io/best-wishes/ and defaults to English. Use the language
button for Chinese. All dependencies and artwork are served from this folder.
No build step, account, backend, payment, analytics, or external API is required.

Five activities: a quiet wish, one-word reflection, seasonal date, appreciation
of personal effort, and a private note with a preset response. They do not
predict events. Text and optional photos are processed in the current browser;
leaving an activity clears the visible input. No user input is sent to a server.

The 3D scenery uses Three.js (MIT; see LICENSE.txt and provenance.json).
The pendant base is AI-generated art. Downloaded text follows the selected
language. The page respects reduced-motion preferences and supports a text
fallback when WebGL is unavailable.

The surrounding academic homepage is unchanged except for a small leaf link
next to Project Demo, opening this standalone page in a new tab.
